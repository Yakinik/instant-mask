## レビュー

### 枠表示のトグル

ツールバーの操作群に配置。押下状態はボタンの見た目（`default` / `ghost`）と `aria-pressed` で示す。

OFF の間は枠とハンドルを消すだけでなく、**範囲ドラッグも止める**（仕上がり確認中に誤って
領域が増えないように）。カーソルも `crosshair` から既定に戻す。ピンチによる拡大は
確認の役に立つので有効なまま。選択状態は保持するので、ON に戻せば続きから操作できる。

検証: 枠 2 個 → OFF で 0 個、OFF 中にドラッグしても 0 個のまま、カーソルは `default`、
ON に戻すと 2 個に復帰。

### 重なりの移動

レイヤ配列の並びがそのまま描画順（末尾ほど前面）。`moveLayer(id, ±1)` で入れ替え、履歴に積む。
インスペクタに「背面へ / 前面へ」を置き、端では無効化する。

検証: 重なる 2 領域を作り、最前面のものを背面へ移動 → 重なり部分のピクセルが変化し、
移動後は「背面へ」が無効・「前面へ」が有効に切り替わることを確認。
