# 編集状態の永続化・スタンプ履歴・文字スタイル

## 要求

1. 編集状態全体を保存し、リロード等で復帰できるようにする
2. 絵文字・文字に履歴を設ける（絵文字 1 文字の入力も履歴に残す）
3. 文字のスタイル（文字の色 / 透過度、アウトラインの色 / 太さ / 透過度）

## レビュー

### 1. 永続化（IndexedDB）

**localStorage ではなく IndexedDB を採用した。** 画像を含めると localStorage の 5MB 制限を
確実に超えるため（4000×3000 の写真は base64 で 10MB 超）。IndexedDB なら Blob をそのまま置け、
画像とレイヤを 1 レコードにまとめられるので両者の整合も崩れない。
履歴のように小さいものは localStorage のままにした。

- 保存対象: 元画像の Blob（名前・MIME 込み）、レイヤ配列、マスクの既定設定、既定の文字スタイル
- 契機: signals の `effect` で変化を拾い 500ms デバウンス
- 復元: 起動時に読み、Blob をデコードして復帰。表示倍率は保存せず常に全体表示から始める
- 壊れたデータや形式違い（`version`）は読み捨ててから削除する
- 復元が終わるまで画面を出さない（一瞬 DropZone が見えるのを防ぐ）

`LoadedImage` に元 Blob を持たせた（従来は ImageBitmap しか持っておらず、再保存できなかった）。

検証: 画像 + マスク + テキストを作ってリロード → 画像・レイヤ 2 件・スタイルすべて復元。

### 2. スタンプ履歴

入力欄から追加したものを新しい順に最大 16 件、localStorage に保持。ピッカーの先頭に
「最近使ったもの」としてチップ表示する。プリセットからの選択は一覧にあるので残さない。
絵文字 1 文字でも複数文字のテキストでも同じように残る。

### 3. 文字スタイル

`EmojiLayer.style` として保持し、専用ダイアログで編集する。項目が 5 つあるので
ツールバーには並べずダイアログにした（狭幅でツールバーが肥大するのを避けるため）。

- 文字の色 / 不透明度
- アウトラインの色 / 太さ（フォントサイズ比 0〜40%）/ 不透明度
- 「既定に戻す」

不透明度は `globalAlpha` で掛ける（カラー絵文字は `fillStyle` が効かないため、
こうしないと絵文字だけ透過しない）。レイヤ選択中はそのレイヤを、未選択なら
「次に作るものの既定」を編集する（ダイアログのタイトルで区別）。
