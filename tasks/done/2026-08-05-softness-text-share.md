## レビュー

### 1. ピンチ中に領域が作られる

**原因**: 指を離す順序。1 本目が離れた時点で `pointers.size < 2` となり `pinchRef` が null に
戻るため、その直後（bubble フェーズ）に走るドラフト確定処理が「ピンチ中なら中断」の判定を
すり抜けていた。

**対処**: 「このタッチ列でピンチが起きたか」を `pinchedRef` として別に保持し、確定処理は
そちらを見る。新しいジェスチャの開始時（触れている指が 0 本の状態からの pointerdown）に
リセットする。

**検証中に見つけた副次バグ**: マウスの pointerdown はタッチ用の追跡を通らないため、
ピンチの痕跡が残ったままマウス操作をすると領域が一切作れなくなっていた。
`startDraft` の冒頭でも、指が 0 本ならリセットするようにして解消。

### 2. ボカシがモザイクのまま

**原因**: WebKit（Safari エンジン）では `ctx.filter` が**存在しない**（`typeof` が `undefined`）。
代入自体は通るがブラーは一切効かない。従来の `supportsCanvasFilter()` は
`typeof ctx.filter === 'string'` しか見ていなかったため、常にモザイクへフォールバックしていた。

**対処**: 16x16 の Canvas に実際にブラーを掛け、境界の外側に滲みが出るかを測る
`supportsCanvasBlur()` に置き換え。効かない環境では**縮小してから補間つきで引き伸ばす**
フォールバック（`drawDownsampledBlur`）を使う。モザイクと違いブロック境界が出ないので
ぼかしとして通用する。WebKit で効果が切り替わることを実測で確認
（ボカシ sd 38.45 / モザイク sd 59.43）。

Chrome のネイティブブラー（sd 11.62）に比べるとフォールバックはやや粗い。
文字は判読不能なので実用上は足りるが、品質を上げるなら ImageData ベースの box blur が要る
（コードサイズとのトレードオフ）。

### 3. 柔らかさ（境界のフェザー）

エフェクト済みの画像をオフスクリーンに 1 回だけ作り、少しずつ内側へ縮めた図形でクリップしながら
`globalAlpha = 1/(steps-i+1)` で重ね塗りする。累積不透明度が外周 1/steps → 中心 1 の線形になり、
リングごとに描くのと違って継ぎ目が出ない。エフェクトの計算は 1 回だけなので負荷は増えない。
柔らかさ 0 のときは従来どおり 1 回のクリップで描く。

### 4. テキスト入力

`EmojiLayer.char` に任意文字列を入れられるようにし、作成時と大きさ変更時に `measureText` で
幅を測って枠と一致させる。絵文字のみか（`\p{Extended_Pictographic}` を含み文字・数字を含まない）で
判定し、テキストには白字＋黒フチを付けて背景に埋もれないようにした。
入力欄は iOS で自動拡大されないよう `font-size: 16px`。

**あわせて修正**: マスク選択中は下部 UI がインスペクタに切り替わり、絵文字ボタンが消えて
追加できなかった。「絵文字・文字」ボタンを操作群（Undo などの並び）へ移して常時表示にした。

### 5. カメラロール保存

`navigator.share({ files: [...] })` で共有シートを開く。iOS / Android はここから写真に保存できる。
**モバイル判定を入れ、デスクトップはダウンロードのまま**にした（Mac Chrome でも共有シートが
開いてしまい不便なため）。判定は UA-CH の `mobile`、UA 文字列、iPadOS 向けに
`maxTouchPoints > 1 && Macintosh` の組み合わせ。AbortError（シートを閉じただけ）はエラー扱いしない。

**実機確認は未実施**（iOS / Android 実機が手元にないため）。共有シートが出るか、
そこから写真に保存できるかはユーザーの確認が必要。

### 残っている課題

- テキストスタンプは、グリフの高さがフォントサイズをわずかに超えるため枠から少しはみ出す。
  操作ガイドとしては実用上問題ないが、厳密に合わせるなら `actualBoundingBoxAscent/Descent` で
  実寸を測る必要がある。
- フォールバックのボカシは Chrome のネイティブブラーより粗い（上記 2 参照）。
