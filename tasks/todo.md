# 枠オフ時の選択・ホイール拡縮・ページズーム無効化

## 要求

1. 枠オフの状態でエリア・絵文字をクリックしたら、枠をオンに戻して選択状態にする
2. PC ではマウスホイールで拡縮する（未選択＝キャンバス、選択中＝選択したもの）
3. コンテンツ（ページ全体）の拡縮を無効にする。キャンバス・エリア・文字の拡縮は維持

## レビュー

### 1. 枠オフでの選択

枠を隠しても DOM からは外さず、枠線と影だけ透明にして当たり判定を残した。
触れたら `showFrames` を戻してそのレイヤを選択する。**この pointerdown では移動を始めない** —
戻った瞬間に意図せず動いてしまうため、ドラッグは次の操作から受け付ける。

検証: 枠オフ時も枠要素は DOM に存在し、`border-color` は `rgba(0,0,0,0)`。
クリックすると枠が戻り、インスペクタ（削除ボタン）が現れる＝選択済み。

### 2. ホイール拡縮

| 操作 | 対象 |
| --- | --- |
| ホイール（選択中） | そのレイヤを等比拡縮 |
| ホイール（未選択） | キャンバス |
| ⌘/Ctrl + ホイール | 常にキャンバス（トラックパッドのピンチ経路） |
| Shift + ホイール | パン |

**パンの割り当てを Shift + ホイールに移した。** 従来はホイールがパンだったが、拡縮に使うため
行き先が必要になった。

レイヤ拡縮は微調整したいことが多いので、ビューより効きを控えめにしている
（1 ノッチあたり約 1.16 倍。ビューは約 1.4 倍）。またホイールを回している間ずっと履歴が
積まれないよう、操作が 400ms 途切れてから次の 1 回だけ積む。

検証: 選択中のホイールでレイヤだけが拡大しキャンバスは不変。未選択ではキャンバスが拡大し、
枠の見かけ比率がキャンバスの比率と一致（レイヤ自体は不変）。

### 3. ページの拡縮無効

- viewport meta に `maximum-scale=1, user-scalable=no`
- iOS Safari はこれを無視するため、`gesturestart` / `gesturechange` / `gestureend` を
  document で直接止める
- body に `touch-action: manipulation`（ダブルタップ拡大の抑止）。ステージは従来どおり
  `touch-action: none` なので、編集用のピンチには影響しない
