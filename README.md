# Instant Mask

ブラウザだけで画像にボカシ・モザイク・絵文字を重ねられるツールです。
画像の処理はすべて端末内で完結し、どこにも送信されません。

**https://yakinik.github.io/instant-mask/**

- ボカシ / モザイク（四角・丸）を範囲指定、強さを調整
- 絵文字スタンプを配置して拡大・縮小・回転
- 元の解像度のまま PNG / JPEG で保存（EXIF は除去されます）

ソースは `develop`、公開ファイルは `pages` ブランチにあります。
